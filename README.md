A static, investor-oriented corporate website for Eco Solutions (Pty) Ltd.

- About Eco Solutions

- Investor / Partner Opportunities
- Projects & Track Record
- Investor / Partner enquiry form

- Google Maps location links/embed
- Download Company Profile button
- Eco Solutions branding and responsive design

## GitHub Pages
Put `index.html` at the repository root. GitHub Pages can publish a static HTML/CSS/JavaScript site directly from a repository.

## Form behaviour
GitHub Pages is static hosting, so the enquiry form uses:
- `mailto:` to prepare an email enquiry
- WhatsApp Click-to-Chat to prepare an enquiry for the two Eco Solutions numbers

It does not silently transmit messages.

## Source basis
Company facts and figures are based on the supplied Eco Solutions company profile. The site does not add unsupported claims about licences, capacities, contracts or guarantees.
